# Laccaz OS 0.3 — обновление оформления

Дизайн в духе современных macOS: нижний док, верхнее меню, светлые панели, оригинальный фон с волнами, скруглённые элементы и синие акценты. Используются свои графика и код, без ресурсов Apple. Полное преломление/размытие Liquid Glass не реализовано. Прозрачность дока зависит от picom/X11.

Dev Hub переработан: боковая навигация, список папок из ~/Projects, создание проектов, действия Git/venv/Docker, консоль, строка команд, рабочие кнопки закрытия/сворачивания/разворачивания. Окно перемещается за заголовок и изменяет размер за нижний правый угол. Список проектов обновляется при запуске и создании нового проекта.

Сборка выдаёт artifacts/laccaz-os-0.3-amd64.iso. Новый архив заменяет предыдущие файлы проекта. Сохрани .github/workflows/build.yml в корне репозитория; auto, config и scripts должны быть рядом. Старую инструкцию сборки смотри в README-base.md, но имя ISO теперь 0.3.

Снимки previews/surface-desktop.png, surface-clipboard.png и devhub-modern.png получены с реально запущенных Qt-приложений в режиме offscreen; это не снимки загруженного ISO. Экран входа SDDM и приложения третьих сторон не имеют полностью собственного дизайна. Их оформление может отличаться. Интеграция X11, композитор и полный ISO ещё требуют проверки в VM.

## Реализовано
- Своя рабочая поверхность с волновым фоном, верхним меню и доком.
- Нижний док с собственными иконками и верхняя строка меню.
- Поиск установленных приложений по desktop-файлам, запуск через gio.
- Свой просмотр папок и открытие файлов; пока без переименования, удаления и копирования файлов.
- Проекты из ~/Projects и переход в Dev Hub для создания проектов.
- Текстовый буфер: поиск, повторное копирование, очистка, пауза, до 40 фрагментов. Только память текущего сеанса, не диск; изображения и файлы не сохраняются. Подсказки конфиденциальности KDE учитываются, но не все приложения помечают пароли — включай паузу перед их копированием.
- Переключение окон через wmctrl, Alt+Tab; терминал Win+Enter; закрытие Alt+F4.

## Что ещё стандартное
Экран входа SDDM, оформление окон Openbox, редактор Kate, терминал Konsole, уведомления и системные настройки не переработаны полностью. Центр уведомлений, настройка сети в Surface, собственная блокировка и горячая клавиша буфера ещё не реализованы. Это рабочий прототип оболочки, а не завершённая новая среда рабочего стола. Нет гарантии уникальности относительно всех других ОС.

## Сборка
Путь для сборки на Debian 13 приведён в README-base.md. Команда: sudo bash scripts/build.sh. Результат artifacts/laccaz-os-0.3-amd64.iso.

Для GitHub загрузи СОДЕРЖИМОЕ папки laccaz-os в корень репозитория вместе с .github/workflows/build.yml, auto, config, scripts. Workflow внутри этого архива рассчитан на такую структуру. Если оставляешь вложенную папку, workflow нужно адаптировать; старый workflow в корне репозитория также нужно заменить. Репозиторий в этой сессии не изменялся.

## Запуск после установки
В SDDM выбери «Laccaz Surface (X11 Preview)». Для возврата к обычной среде выбери Plasma. В Live-сессии автологин зависит от live-config и должен быть проверен; если открылся KDE, выйди и выбери Surface. Для предварительного просмотра приложения на Debian с установленным python3-pyside6.qtwidgets: python3 config/includes.chroot/usr/share/laccaz/shell.py --preview. Preview открывает отдельные окна и не заменяет текущий рабочий стол.

X11 нужен для глобального текстового буфера, управления окнами и резервирования места под панель. Wayland-сеанс Surface не реализован. Сначала проверь новый ISO в виртуальной машине. Поддержка нескольких мониторов пока отсутствует; панель рассчитана на основной монитор.
